# media

Voice and video notes for the design boards. Excalidraw can't hold audio or video, so the files live here.

- **Name:** `YYYY-MM-DD-topic`, for example `2026-11-14-workbench-sounds.m4a`.
- **On the board:** drag the grey "Voice or video note" card from the library and write the same name on it.
- **Content:** made by people (see [CONTRIBUTING.md](../../CONTRIBUTING.md)). Licence: CC BY-SA 4.0.
