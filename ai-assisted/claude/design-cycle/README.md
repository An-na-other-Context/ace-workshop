# design-cycle

Tools from Anna (@annaothercrow)'s solo design-thinking toolkit, rebuilt for ACE Workshop.

> **AI-made.** Claude (AI) extracted the text and sources from Anna's private toolkit and wrote every file here. No toolkit file was copied. The choices are Anna's.

## How the cycle works here

- **A cycle starts from a research question** (or a few), built on a **design thesis**. How to word both is still open: issue [#28](https://github.com/An-na-other-Context/ace-workshop/issues/28) looks into it. Until then, the [Problem statement](1-understand/problem-statement/problem-statement.md) and How might we rules guide the wording.
- **Seven phases:** Understand · Observe · Define point of view · Ideate · Prototype · Test · Reflect. Each phase makes artifacts with tools from the toolbox, and the findings get documented.
- **A run is an item.** Each item on the [ACE Workshop board](https://github.com/orgs/An-na-other-Context/projects/1) is one run: a session of setting out to do something, from the start to whatever form the finish takes, logged on its issue.
- **The design board is the research and design place in one** ([design/](../../../design/README.md)). The GDD mind map on it is an artifact of Ideate.
- **Where the cycle stands (14.11.2026):** just started, in phases 1–3. No solution can be known yet.
