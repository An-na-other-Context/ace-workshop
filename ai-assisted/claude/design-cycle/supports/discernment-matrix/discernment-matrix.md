# Discernment matrix

**Support card** · used by the tools of the [design cycle](../../README.md) whenever something gets chosen

> **AI-made.** Drafted by Claude (AI) from Anna (@annaothercrow)'s solo design-thinking toolkit. The matrix itself is Anna's (July 2026). See [Who made what](#who-made-what) and [Sources](#sources).

Board version: [discernment-matrix.excalidraw](discernment-matrix.excalidraw). Open it in Excalidraw or in VS Code.

Anna's tool for choosing by criteria instead of a gut pick. Walked **out loud, with Claude**, not filled in silently. The point isn't the grid: it's being reasoned with instead of following the pull of a shiny thing.

## Bookmark first

Without it, the four questions get answered about a different thing than the one you're holding.

## The four questions

| # | The question | What it really asks | Goes forward if |
|---|---|---|---|
| 1 | New, or does it keep coming back? | a one-off, or a pattern wearing a new hat | it keeps coming back |
| 2 | Does it add value right now? | today, not in an imagined version of the project | yes, now |
| 3 | Easy or hard with what I have? | the tools, energy and time actually on hand | doable with what is here |
| 4 | Does it get costlier if I wait? | what waiting actually costs, not what it feels like | costlier |

**No points, no totals, no threshold.** Four answers, then a read. The pattern across the four is the answer.

## Rewording it for a tool

The items change; the four questions don't. Rewording is a change to a keeper, so say it out loud when it happens.

| Tool | The item |
|---|---|
| Problem statement | each problem definition |
| Jobs to be done | each job |
| Critical items diagram | each of the eight items |
| Customer journey map | each low point |
| How might we | each question |
| Define success | each measure |
| Brainstorming | each idea that survived clustering |
| Special brainstorming | each clustered idea |
| Analogies & benchmarking | each borrowed idea |
| NABC | the cross, once both halves hold |
| Prototype to test | each thing to build |
| MVP | each candidate feature |
| Retrospective sailboat | each anchor |

## Where it does not apply

- **Capturing and sorting:** AEIOU's five blocks, the feedback capture grid, I like / I wish. Nothing is being chosen.
- **The 2x2 matrix:** it already is a criteria matrix. Its axes are the criteria, named before anything moves.
- **The sailboat's cliffs:** risks you have no power over. Naming them is the whole point.

## Where it comes from

- **17.07.2026, made for shiny ideas.** The first idea was to park a shiny idea for 5–10 minutes and move on. Anna expected to overrule that the moment an idea had real pull, so it became two paired pieces: the matrix, talked through live with Claude, and the bookmark, written before the walk so the original thread can't get lost.
- **21.07.2026, tested live** on a real shiny idea. In Anna's words, the "object pull was blinding". Walking the four questions cut through it, and the idea became a planned future feature instead of a new project.
- **Status in the toolkit:** a confirmed keeper. The form isn't revised unless Anna asks.
