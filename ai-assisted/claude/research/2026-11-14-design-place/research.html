In short

No tool ticks both must-haves for sure.Offline is easy to find. Voice and video on the board is the hard part: in most tools it isn't confirmed for the offline version.
Closest pinboard: tldraw offline (F1).Free, no account, works offline on Windows; sticky notes, frames, images, drawing. Video clips probably work, there's no audio-only note, and it isn't open source.
Recording your voice inside the app, offline:Xournal++ (F4) links audio to what you draw, but it's a notebook, not a free board. OneNote (F8) records audio and video, but whether it works without an account is unclear. Otherwise: record in another app and drop the file on the board.
Open-source boards: AFFiNE (F2) and Logseq whiteboards (F6).Both are local and free. Whether audio and video play on them isn't confirmed.
Research: people differ a lot (F12–F21).No single "neurodivergent preference". What repeats: choose text, voice or picture per note; keep the board calm; have a starting structure you can change or ignore.

  1. F1tldraw offline: a free desktop app with "no accounts and no server"; Windows installers. Sticky notes, frames, images, freehand drawing, arrows. Video clips (mp4, webm, mov) are the toolkit's default, but the offline app's docs don't confirm them; there is no audio-only note. Everything sits in one .tldraw file; it doesn't merge changes made elsewhere, so edit it in one place at a time. Not open source ("All rights reserved"). The toolkit has reduce motion, keyboard moves and dark mode. Latest release 12.11.2026. Docs Docs
  2. F2AFFiNE: open source (MIT). Local workspaces need no login and are free without limit. Its "edgeless" whiteboard mode has sticky notes, shapes, text, web embeds and templates (vision board, ADHD planner and more). Files can sit on the board; whether audio or video play there isn't confirmed. Voice recording is macOS only. Data stays in AFFiNE's own storage; plain Markdown files are only planned. The newest builds are test versions. Frames: memory, not checked. Docs Docs
  3. F3Noteey: works offline; an account is needed only for paid plans. Audio and video files can go on the board, with time-stamped notes on them; also images, sticky notes, sketches, links, PDFs, mind maps. The free plan is small: 3 projects, 100 cards, 3 audio/video notes. Desktop Pro costs $99 once. Closed source; the file format isn't stated. Docs Docs
  4. F4Xournal++: free and open source (GPL-2.0), for Windows. It records audio while you write; tap a stroke to hear that moment again. Pages like a notebook, not a free board; no video. Files are .xopp (compressed text). Latest release 26.09.2026. Docs Docs
  5. F5OpenBoard: a free teaching whiteboard (GPL-3.0), no registration, Windows 10 and up. Local audio and video work, with known bugs. Page and slide based. Files are .ubz (zipped pages). Docs Docs
  6. F6Logseq whiteboards (the older "OG" version): AGPL-3.0, local. Boards are text files in a folder, which suits git. Video works; audio is unreliable in forum reports summary only. The OG version now only gets security fixes, and whiteboards may be missing from the new version summary only. Docs Lived
  7. F7Excalidraw (again from round 1): MIT, free; an installable web app that works offline and saves in the browser; .excalidraw files are JSON. Frames exist summary only. No local audio or video; web embeds need internet. Docs Docs
  8. F8OneNote desktop: records audio and video straight into a page. Free. Using it without a Microsoft account worked in 2021 Opinion; newer reports conflict summary only. Closed .one format. Free placement and page templates: memory, not checked. Docs
  9. F9Kinopio, fails offline: its help page says it can't open without internet (its llms.txt file says the opposite). Holds audio and video files and cards. Free up to 100 cards, then $8 a month or $250 once. Docs Docs
  10. F10Milanote, fails offline: the Windows app is a web app installed after login. Audio and video upload; game design document templates Opinion. One developer rebuilt their design document in it and found the boards read "like chapters" Example. Docs
  11. F11JSON Canvas, an open (MIT) file format for boards: text, file, link and group items, 6 colour presets. Only Obsidian and Charkoal save in it directly, so it doesn't help without Obsidian. Docs Docs

Q2 · People like the profileWhat research and first-person accounts say about visual boards. F12–F22
  1. F12Autistic adults with a digital whiteboard (20 people): it gave them something to point at, extra thinking time and control over the pace; it also cost effort (learning the tool, screen load, talking and drawing at once). It moves the mental load rather than lowering it. Advice: make the visual part optional, try the tool first, plan breaks, keep the structure adjustable. Study
  2. F13Autistic students (12) preferred structured text to pictures: a minimal, muted look and flat navigation; images only when they show what text can't; they wanted to choose for themselves and adjust how much is shown. Study
  3. F14Some autistic adults report thinking in pictures more often, "some", not all. Study summary only
  4. F15Neurodivergent professionals (36): bright colours and moving things distracted ADHD participants; several dyslexic participants preferred speaking to typing, one autistic participant the reverse. Needs clashed between people, so offering both ways matters. Study
  5. F16Dyslexic adults (11): writing was the bigger barrier for 10 of them; several found black on white hard and suggested cream, red or yellow backgrounds; one wanted a "skeleton" to fill in instead of a blank page. Study
  6. F17Visual layouts that show how ideas connect helped students with learning disabilities: 16 studies, 808 school students, moderate to large effects. Keywords and simple drawings beat long sentences. Children with teacher-made layouts, not adults on free boards. Review
  7. F18ADHD adults: problems come from tools that expect steady self-control and step-by-step time Study summary only. Outside aids help, but no strategy works for everyone Review.
  8. F19An ADHD whiteboard user: a board on the wall beats a hidden planner ("out of sight, out of mind"); wiping it clean lowers shame; without structure it turns into "wall decor" or a dumping ground. Lived
  9. F20Clutter: constant visual input is tiring, empty space rests the eyes, some stimulation is fine Lived. An AuDHD writer: "Without structure I get lost" Lived.
  10. F21Much ADHD tech research tries to reduce ADHD traits and rarely designs together with people who have ADHD, which supports designing your own board. Review summary only
  11. F22Visible piles work as reminders, from an old office study of 10 workers. Study summary only
Q3 · Setting it upDo and don't, from sources; plus the helper's own ideas, marked.

Do

  • A starting structure (frames, a "skeleton"), kept optional and changeable (F12, F16, F19, F20).
  • A calm look: muted colours, empty space, nothing moving or flashing, motion you can switch off (F13, F15, F20) Guideline.
  • Each note as text, voice or picture, whatever fits that moment (F13, F15).
  • Images only when they carry information; text as keywords (F13, F17).
  • Your own background colour and font, e.g. dark (not black) text on a light (not white) background (F16) Guideline summary only.
  • Easy undo and going back; nothing that relies on memory Guideline.
  • One page or area per topic; when something changes, replace the old version so only the current one shows Example Example.
  • A short trial before moving everything in, with a fallback (F12).

Don't

  • Expect one setup to work for everyone, or to keep working forever (F18).
  • Let notifications or sounds interrupt (F15).

The helper's own ideas AI idea

  • One board per game area (core loop, learning goals, levels, characters, art mood, sound mood), plus a fixed "Start here" frame.
  • At most 4–6 colours, each with one fixed meaning.
  • Voice and video files named by date and topic, so they can be found outside the tool.
  • Media files in a project folder next to the board file.

GlossarySpecial words on this page.
Offline
Working on your PC without an internet connection.
Open source
The program's code is public, and anyone may use, change and share it under its licence. "Closed source" means the code is private.
MIT, GPL, AGPL
Open-source licences. MIT allows almost anything. GPL and AGPL require that changed versions stay open too (AGPL also covers programs run over the internet).
Board, canvas
An open surface where notes, pictures and clips can be placed anywhere, like a pinboard.
Edgeless mode
AFFiNE's name for its board view.
Workspace
A container for all your boards and pages in a tool.
Frame
A labelled box on a board that holds a group of notes together.
Template
A ready-made starting layout you can fill in.
Sticky note
A small coloured note card on a board.
Embed
Content from somewhere else (a video, a web page) shown inside the board.
mp4, webm, mov, m4a
File types for video clips (mp4, webm, mov) and audio clips (m4a).
.tldraw, .xopp, .ubz, .one
The file types tldraw, Xournal++, OpenBoard and OneNote save their boards or pages in.
JSON
A common text format for data that both people and programs can read.
JSON Canvas
An open file format for boards, built on JSON.
SQLite
A small database stored in one file; readable only with database tools.
Git
The tool behind GitHub that saves versions of files and shows what changed between them.
OG version
Logseq's older version ("original"), kept alongside a newer one.
llms.txt
A text file some websites publish to describe themselves for AI tools.
Test versions
Early builds released before a version is finished (also called pre-releases).
Graphic organizer
A visual layout that shows how ideas connect, such as a chart or a map of boxes and arrows.
Meta-analysis
A study that pools the results of many studies to see the overall effect.
CHI, CSCW, ICWSM
Research conferences on computers and people, teamwork with computers, and social media.
AuDHD
Being both autistic and ADHD.
Abstract
The short summary at the top of a research paper.
Search snippet
The few lines a search engine shows under each result.
Second-hand
A page that reports someone else's study instead of being the study itself.
Saved copy
When the web reader showed a PDF as raw code, the helper opened the PDF file the reader had saved on this PC.
Preprint, arXiv
A paper shared before other researchers have checked it; arXiv is a free online archive for them.
Bot check, bot protection
A page that blocks automated visitors (like the helper) before showing content.
403, 404, 500
Web error codes: 403 = the site refused the request, 404 = the page wasn't found, 500 = the site had an error.
Redirect
A web address that sends you on to a different address.
